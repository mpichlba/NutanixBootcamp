# Lab 6 – VM Migration mit Nutanix Move - Schritt 1: Initiales Setup

**VM Migration mit Nutanix Move - Schritt 1: Initiales Setup**

> In diesem Schritt setzen wir einen Migration Plan auf

Quelle: <https://stephopper.com/published/guide_1777397649752>

[← Zurück zur Übersicht](../README.md)

### Schritt 1

Logge dich ein; die Logindaten bekommst du von dem Vortragenden.

![Schritt 1: Logge dich ein; die Logindaten bekommst du von dem Vortragenden.](images/Lab6_Nutanix_Move_Setup/step_01.png)

### Schritt 2

Klicke auf "Create a Migration Plan"

![Schritt 2: Klicke auf "Create a Migration Plan"](images/Lab6_Nutanix_Move_Setup/step_02.png)

### Schritt 3

Füge als Name "Migration" und deine zweistellige BootcampNummer ein.

![Schritt 3: Füge als Name "Migration" und deine zweistellige BootcampNummer ein.](images/Lab6_Nutanix_Move_Setup/step_03.png)

### Schritt 4

Wähle "NutanixBootcamp" als Source Cluster

![Schritt 4: Wähle "NutanixBootcamp" als Source Cluster](images/Lab6_Nutanix_Move_Setup/step_04.png)

### Schritt 5

Select Target Cluster "NutanixCluster"

![Schritt 5: Select Target Cluster "NutanixCluster"](images/Lab6_Nutanix_Move_Setup/step_05.png)

### Schritt 6

Click on input

![Schritt 6: Click on input](images/Lab6_Nutanix_Move_Setup/step_06.png)

### Schritt 7

Wähle Target Project "None" und Target Cluster "fts-ntnx"

![Schritt 7: Wähle Target Project "None" und Target Cluster "fts-ntnx"](images/Lab6_Nutanix_Move_Setup/step_07.png)

### Schritt 8

Wähle "default-container.xxxx" als Target Container und Klicke "Next"

![Schritt 8: Wähle "default-container.xxxx" als Target Container und Klicke "Next"](images/Lab6_Nutanix_Move_Setup/step_08.png)

### Schritt 9

Click on input

![Schritt 9: Click on input](images/Lab6_Nutanix_Move_Setup/step_09.png)

### Schritt 10

Suche aus der Liste deine zugeordneten VMs aus und Klicke auf + um sie zur Liste auf der rechten Seite hinzuzufügen.

![Schritt 10: Suche aus der Liste deine zugeordneten VMs aus und Klicke auf + um sie zur Liste auf der rechten Seite hinzuzufügen.](images/Lab6_Nutanix_Move_Setup/step_10.png)

### Schritt 11

Wähle als Target Type "VLAN"

![Schritt 11: Wähle als Target Type "VLAN"](images/Lab6_Nutanix_Move_Setup/step_11.png)

### Schritt 12

Wähle als Target Subnet "VLAN2208_unmanaged"

![Schritt 12: Wähle als Target Subnet "VLAN2208_unmanaged"](images/Lab6_Nutanix_Move_Setup/step_12.png)

### Schritt 13

Click on 'Network Map the source networ'

![Schritt 13: Click on 'Network Map the source networ'](images/Lab6_Nutanix_Move_Setup/step_13.png)

### Schritt 14

Warte bis die Kapazitätsprüfung abgeschlossen ist.

![Schritt 14: Warte bis die Kapazitätsprüfung abgeschlossen ist.](images/Lab6_Nutanix_Move_Setup/step_14.png)

### Schritt 15

Belasse den Preparation Mode auf "Automatic" und wähle 'Allow Nutanix Move to add CD-ROM'

![Schritt 15: Belasse den Preparation Mode auf "Automatic" und wähle 'Allow Nutanix Move to add CD-ROM'](images/Lab6_Nutanix_Move_Setup/step_15.png)

### Schritt 16

Fülle Benutzername und Passwort für die VMs aus; diese Daten bekommst du vom Vortragenden.

![Schritt 16: Fülle Benutzername und Passwort für die VMs aus; diese Daten bekommst du vom Vortragenden.](images/Lab6_Nutanix_Move_Setup/step_16.png)

### Schritt 17

Hier belassen wir die Standardeinstellungen - diese werden gemeinsam besprochen - Klicke anschließend auf 'Next'

![Schritt 17: Hier belassen wir die Standardeinstellungen - diese werden gemeinsam besprochen - Klicke anschließend auf 'Next'](images/Lab6_Nutanix_Move_Setup/step_17.png)

### Schritt 18

Klicke auf "Save and Start"

![Schritt 18: Klicke auf "Save and Start"](images/Lab6_Nutanix_Move_Setup/step_18.png)

### Schritt 19

Überwache die nun die Migration indem du auf den Status deines Migrationplans klickst.

![Schritt 19: Überwache die nun die Migration indem du auf den Status deines Migrationplans klickst.](images/Lab6_Nutanix_Move_Setup/step_19.png)
